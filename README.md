## 🚀 Features

- 📸 AI-powered crop disease detection from images
- 💬 Multilingual support (English, Hindi, Gujarati)
- 🤖 Chatbot for instant agricultural advice
- 🏥 Medicine vendor & government scheme recommendations
- 📄 PDF report generation
- 🎨 Modern, animated UI (Tailwind CSS + shadcn-ui)

## 📝 Getting Started

Clone the repo and install dependencies:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

Or use [Lovable](https://lovable.dev/projects/3e22623f-b552-47ad-b820-c1243d67d997) for instant online editing and deployment.

---

## ✨ Usage

1. Upload a crop image or take a photo
2. Let the AI analyze and detect diseases
3. Get instant recommendations, vendor info, and government schemes
4. Chat with the AI for more help
5. Download a PDF report for your records
